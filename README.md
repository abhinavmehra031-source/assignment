# Accredian Enterprise Landing Page

A full-stack enterprise landing page recreation built as a frontend/full-stack assessment. The project focuses on responsive UI, interactive sections, animations, and a lead-enquiry flow.

## ✨ Features

- Responsive enterprise landing page
- Sticky navigation with mobile menu
- Hero section with CTAs
- Animated statistics and partner sections
- Interactive capability and domain sections
- Course/program filtering tabs
- CAT learning framework tabs
- Delivery workflow section
- FAQ accordion
- Testimonials carousel
- Lead enquiry modal and embedded form
- Next.js API route for enquiry submission
- Responsive accessibility and UI polish

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animation:** Framer Motion + CSS animations
- **API:** Next.js Route Handlers

## 🚀 Run Locally

### Prerequisites

- Node.js 18+
- npm 9+

### Installation

```bash
git clone https://github.com/abhinavmehra031-source/assignment.git
cd assignment
npm install
npm run dev
```

Open `http://localhost:3000`.

### Production Build

```bash
npm run build
npm start
```
